# Santaan Daily Content Command Sheet (1 Page)

Date: 2026-03-05  
Who uses this: Content writers + social/reel team + marketing coordinator  
Purpose: Run daily content actions in one flow and update CRM cleanly.

## Daily Timeline (IST)

- 9:30 AM: Open CRM signal snapshot
- 10:00 AM: Finalize today topics (1 patient + 1 social derivative)
- 1:00 PM: Draft complete
- 3:00 PM: Medical/brand check complete
- 5:00 PM: Publish + distribute
- 6:30 PM: Update CRM content log

## Step 1: Pick Topic from CRM (No guesswork)

Choose topics using:
- top patient questions
- top lost reasons
- top objection code
- center trend

Rule: if same question appears repeatedly, publish it this week.

## Step 2: Build One Blog + Two Derivatives

For each selected topic, create:
- 1 blog (patient or doctor)
- 1 short reel script
- 1 carousel or short post

All three must use same intent and same CTA.

## Step 3: Mandatory Metadata (Medium + CRM)

Tags required on Medium:
- audience: `audience-patient` or `audience-doctor`
- center tag
- stage tag
- service tag
- intent tag

CRM fields to log after publish:
- date
- title
- url
- audience type
- center
- service
- stage
- intent
- utm_campaign
- asset_code

## Step 4: Writing Guardrails (Always)

- no guaranteed success claims
- no fixed cost promises
- no medical over-claims
- include personalized-clinical-dependency line
- use clear CTA (Call / WhatsApp / Book)

## Step 5: CTA Standard

Each content piece must end with one direct action:
- `Call +91 9337326896`
- `WhatsApp Santaan`
- `Book Assessment`

No content goes live without CTA.

## Step 6: End-of-Day Update (Required)

Update CRM with:
- what was published
- target audience
- linked campaign/asset
- expected outcome (call/whatsapp/book)
- tomorrow’s follow-up topic

If not updated in CRM, content is treated as incomplete.

## Daily Quality Checklist (Tick Before Close)

- Topic chosen from CRM signals
- Metadata tags complete
- UTM + asset code attached
- Clinical/brand checks done
- CTA included
- CRM updated

Owner sign-off:
- Content Writer: __________
- Marketing Coordinator: __________
- CRM Ops: __________
